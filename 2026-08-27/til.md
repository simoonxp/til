## 💼 Desenvolvimento de Case para Vaga de Estágio

Hoje trabalhei no desenvolvimento de um **case técnico** como parte de um processo seletivo para vaga de estágio na área de dados.

---

### O que aprendi na prática

- Como estruturar um case do zero: entender o problema → explorar os dados → gerar insights → apresentar resultados
- A importância de contar uma **história com os dados**, não apenas listar números
- Como priorizar os insights mais relevantes para o negócio
- Como apresentar conclusões de forma clara e objetiva para quem não é técnico

---

### Etapas do case

1. **Entendimento do problema** — qual pergunta de negócio precisa ser respondida?
2. **Exploração dos dados** — o que os dados dizem? Existem outliers, valores nulos, padrões?
3. **Análise** — cruzamentos, agrupamentos, cálculos de métricas
4. **Visualização** — escolher o gráfico certo para cada insight
5. **Conclusões** — o que recomendar com base nos dados?
