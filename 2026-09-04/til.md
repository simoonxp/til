---

### Estatística Descritiva

| Medida | O que é | Fórmula |
|---|---|---|
| **Média** | Soma dividida pela quantidade | `μ = Σx / n` |
| **Mediana** | Valor central dos dados ordenados | valor do meio |
| **Moda** | Valor que mais se repete | — |
| **Variância** | Média dos quadrados dos desvios | `σ² = Σ(x-μ)² / n` |
| **Desvio Padrão** | Raiz da variância | `σ = √σ²` |

---

### Probabilidade

```
P(A) = número de casos favoráveis / número de casos possíveis

P(A) sempre entre 0 e 1
P(evento certo) = 1
P(evento impossível) = 0
```

**Regras básicas:**
- `P(A ou B) = P(A) + P(B) - P(A e B)`
- `P(A e B) = P(A) x P(B)` — se A e B forem independentes
- `P(não A) = 1 - P(A)`
